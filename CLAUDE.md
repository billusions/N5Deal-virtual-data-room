# N5Deal — Virtual Data Room QA Assignment

## Context
This repo holds deliverables for a Product QA practical assignment for an N5Deal job application. The hiring process favors practical thinking and values over theoretical evaluation.

- Product under test: https://github.com/evo9/virtual-data-room
- Original requirements: https://github.com/evo9/virtual-data-room/blob/main/task.md
- Deployed app URL and test accounts: see that repo's README
- Time budget: 24 hours from start of work

## Goal
Test the Virtual Data Room product and implement automated tests, building the start of a reusable QA automation framework based on the testing pyramid.

## Task
- Prepare a short test plan.
- Test the product (manual, exploratory, automated).
- Document bugs, product issues, and missing cases.
- Group and prioritize findings.
- Automate the most valuable scenarios.
- Build the beginning of a reusable QA automation framework (testing pyramid).
- Prepare a short QA report covering: what was tested, key issues/risks, automated coverage, release readiness, what to test/automate next.

## AI usage
AI usage is encouraged and must be briefly disclosed in the deliverables (where/how it was used for test design, automation, analysis, etc.).

## Deliverables
- Test plan
- Prioritized bug / findings report
- Automated tests
- Short description of the testing approach
- Final QA report

## Evaluation focus
Approach, prioritization, and quality of decisions — not the number of test cases or bugs found.
